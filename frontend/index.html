CryptoPad user guide

×

CryptoPad encrypts text locally in this app. You can type a note or import a plain text file, then save the encrypted result as a protected CryptoPad .txt file.

  1. 01

    Start a session

    Create a master key with at least 12 characters and confirm it. Keep it safe: saved notes need this key to decrypt.

  2. 02

    Write or select a file

    In the workspace, type in the editor or choose a .txt file. You can also drop a text file onto the editor. Its contents are loaded into the editor for encryption.

  3. 03

    Encrypt and save

    Select “Encrypt message” to create an encrypted packet. Select “Save as .txt” to download a note that includes the packet and a master-key-protected private key.

  4. 04

    Open and decrypt a note

    On this page, choose or drop a saved CryptoPad .txt file (or paste its contents), enter the same master key, and select “Decrypt Message”. Raw JSON packets can also be decrypted in the original active workspace session.

Educational prototype only. Avoid entering sensitive information. A lost master key cannot be recovered.

THE MATH BEHIND THE MARK

How ElGamal works

×

ElGamal uses a public key to establish a shared secret with a fresh random value. CryptoPad then derives an AES key and uses authenticated encryption for the note content.

  1. 01

    Key generation

    Choose private x and publish y = gˣ mod p.

  2. 02

    ElGamal encapsulation

    Choose fresh random k; compute c₁ = gᵏ mod p and shared secret yᵏ mod p.

  3. 03

    Hybrid encryption

    Derive an AES-256 key with HKDF-SHA256, then encrypt the message using AES-GCM.

  4. 04

    Decryption

    The private key computes c₁ˣ mod p to recreate the shared secret and decrypt/authenticate the message.

Educational prototype only. Use a vetted, standardized protocol and security review for real sensitive information.
